# اقرأ أولًا — THURAYA MASTER CONTENT / CURSOR PACKAGE v1.0

## الهدف
هذه الحزمة هي المرجع التنفيذي الوحيد لبناء الموقع الشخصي العام لثريا الشامسي.

الموقع:
- **شخصي عام** وليس موقع جهة عمل.
- منصة معرفة واستدامة وابتكار وجودة حياة ومجتمع.
- لا يعرض أرقامًا أو مؤشرات أو عقودًا أو نتائج أو مراسلات داخلية تخص أي جهة عمل.
- لا يذكر الجائزة للعامة ولا يبني تجربة المستخدم حول الترشح.
- العربية هي المحتوى الأصلي، والإنجليزية نسخة مترجمة آليًا قابلة للمراجعة اليدوية.
