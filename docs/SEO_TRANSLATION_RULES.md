# SEO & TRANSLATION RULES

## URLs
Arabic: `/ar/...`
English: `/en/...`

## العربية
- Source of Truth.
- RTL شامل النصوص والنماذج والأسهم وBreadcrumbs.

## English
- Auto translate at publish.
- Store/cache.
- Manual Override.
- LTR كامل.

## Publication Dates
- seeded launch library: `show_publish_date=false` افتراضيًا.
- بعد الإطلاق: يسجل تاريخ النشر الحقيقي ويمكن عرضه.
- يمنع Backdating.

## SEO
لكل صفحة:
- title
- description
- canonical
- hreflang ar/en
- OG title/description/image
- robots
- structured data عند الملاءمة

## NoIndex
- Staging
- Admin
- Draft
- Preview URLs

## Content
لا تستخدم SEO Titles توحي بأن الموقع يمثل حكومة أو جهة عمل.
