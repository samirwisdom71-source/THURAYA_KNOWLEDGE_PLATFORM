# دليل لوحة الإدارة

## الدخول

المسار `/admin`. حساب المدير يُنشأ مرة واحدة فقط في أول تشغيل عندما لا يوجد أي مدير نشط.

## المحتوى

من **المحتوى → إضافة محتوى** اختر أي نوع من الأنواع الـ14. كل سجل يحتوي:
- تبويب عربي وإنجليزي.
- Slug ثابت داخل نوع المحتوى.
- حالة: مسودة، جاهز، منشور، مؤرشف، بانتظار صورة.
- ظهور: عام، خاص، غير مفهرس.
- خيار إظهار تاريخ أول نشر الحقيقي.
- حقول داخلية JSON لا تخرج للعامة.

زر **حفظ ونشر** لا يقبل تاريخ نشر من المستخدم. أول نشر جديد يسجل وقت الخادم فقط. السجلات التاريخية seeded لا يُخترع لها تاريخ.

## الصور والملفات

1. ارفع الملف من **الصور والملفات**.
2. أدخل Alt بالعربية والإنجليزية عند الحاجة.
3. حدد حالة الموافقة.
4. افحص الملف بصريًا ومعلوماته، ثم فعّل `Public-safe review`.
5. غيّر الظهور إلى Public فقط بعد المراجعة.
6. اربط Asset بالمحتوى من محرر السجل.

الأصل يبقى في private storage. الصورة العامة هي مشتق WebP معاد الترميز، ولا تُخدم الميديا للعامة دون المراجعة والـvisibility المناسبين.

## الإصدارات

الغلاف والملف الكامل يمكن ربطهما من سجل Publication. `full_document_public` يجب أن يبقى False ما لم يكن الملف نفسه مرفوعًا ومراجعًا وعامًا. أدوات الإصدار وFAQ سجلات مستقلة ويمكن تعديلها بالكامل.

## المصادر

من **المصادر** أضف source key جديدًا أو عدل أي مصدر. المقال يربط المصادر باستخدام `source_keys`. النظام يرفض نشر/حفظ مقال بمفتاح مصدر غير موجود.

## روابط الإصدارات

من **روابط الإصدارات** عدل المقالات والأدوات المرتبطة بكل إصدار. يمكن استخدام Legacy ID للإصدارات الأصلية أو slug لإصدار جديد.

## المشاركات

أسئلة الزوار ومشاركات التحديات لا تُنشر تلقائيًا. من **المشاركات** راجع الـpayload، أضف ملاحظة داخلية، ثم اعتمد/ارفض/Spam/أعد للمراجعة.

## المشتركين

يمكن تعديل status إلى `active / unsubscribed / bounced` وتصدير CSV. لا توجد أرقام تجريبية أو seeded subscribers.

## الإعدادات

اسم الموقع، Hero، About، الصور الرئيسية، وHome featured محفوظة في DB. Advanced JSON مخصص للهوية واختيارات الصفحة الرئيسية دون تعديل الكود.
