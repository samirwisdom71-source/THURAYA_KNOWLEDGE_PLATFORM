# IMAGE & MEDIA REQUIREMENTS

## المطلوب قبل Go Live
1. صورة شخصية Hero احترافية لثريا — عمودية عالية الدقة.
2. صورة About طبيعية غير رسمية أكثر من Hero.
3. أغلفة الكتب الستة.
4. 12–24 صورة عامة من:
   - تعلم وقراءة
   - ورش/جلسات معرفة
   - تطوع/مشاركة مجتمعية
   - استدامة
   - كتابة/تأليف
   - فعاليات عامة
5. لا يلزم ملء 24 Visual Journal كلها يوم الإطلاق؛ يُنشر فقط ما له صورة حقيقية.

## فحص الصورة
- لا شاشة داخلية.
- لا بريد أو أرقام أو أسماء غير مصرح بها.
- لا Badge/ID واضح.
- موافقة أي شخص يمكن التعرف عليه.
- إزالة GPS/EXIF.
- Alt Text عربي/إنجليزي.
- Crop variants: 16:9, 4:5, 1:1.

## الأداء
- Original تحفظ Private.
- Public derivative WebP/AVIF.
- Responsive srcset.
- Lazy load أسفل الـFold.
