# PROJECT GUARDRAILS — قواعد حاكمة لا تقبل التجاوز

## 1. تعريف المنتج
الموقع Personal Knowledge Platform لثريا الشامسي، وليس:
- موقعًا لجهة العمل.
- ملف ترشح للجائزة.
- لوحة إنجازات مؤسسية.
- سيرة ذاتية تقليدية.

## 2. ممنوعات Public
يمنع عرض أو إدخال:
- مؤشرات وأرقام أداء جهة العمل.
- وفورات أو ميزانيات أو عقود.
- تقييمات موظفين.
- مراسلات أو بريد داخلي.
- Screenshots لأنظمة داخلية.
- أسماء أشخاص دون موافقة.
- صور أشخاص دون موافقة مناسبة.
- بيانات شخصية أو مواقع جغرافية دقيقة غير لازمة.
- أي نص يوحي أن الموقع يمثل جهة حكومية.

## 3. النزاهة الزمنية
- `publish_date` = التاريخ الحقيقي فقط.
- يمنع Backdating.
- لا تظهر عبارة «منذ سنة» أو أرشيف تاريخي إلا إذا كانت حقيقة.
- يمكن نشر مكتبة إطلاق كبيرة دون إظهار تاريخ على Cards.

## 4. أرقام الجمهور
- Production يبدأ من صفر.
- لا Demo Metrics في Production.
- أي Demo Data يجب أن تكون `is_demo=true` وفي Staging فقط.
- Production build يفشل عند اكتشاف Demo flag.

## 5. الجائزة
- حقول `award_alignment_internal` Admin-only.
- لا تظهر في HTML أو Public API أو Metadata أو Search Index.
- لا توجد صفحة «الجائزة» ولا عبارة «ملف ترشح».

## 6. المصادر الرسمية
قسم «مصادر ألهمتني» يعرض:
العنوان + الجهة + ملاحظة شخصية قصيرة + رابط رسمي.
لا تنسخ النصوص الرسمية ولا توحي بشراكة أو اعتماد.

## 7. AI
- AI مساعد للترجمة/التصنيف/البحث فقط وفق الحوكمة.
- لا ترسل محتوى حساسًا لخدمات غير معتمدة.
- أي Auto Translation قابلة للمراجعة اليدوية.
